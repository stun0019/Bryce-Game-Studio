# Bryce Game Studio

Bryce Game Studio 是我的個人遊戲開發作品集網站。

這個網站將作為所有遊戲 Demo 的統一入口，收錄目前已完成、正在開發，以及未來預計製作的遊戲作品。

## 線上網站

GitHub Pages：

`https://stun0019.github.io/Bryce-Game-Studio/`

如果網址尚未生效，請先在 GitHub Repository 中啟用 GitHub Pages。

## 目前收錄作品

### Hooded Escape

類型：

- 2D 平台動作遊戲
- HTML 遊戲 Demo
- 個人練習作品

目前內容：

- 角色待機動畫
- 角色眨眼動畫
- 行走與跑步
- 跳躍
- 下蹲
- 攻擊
- 死亡
- 消失動畫
- 基礎遊戲流程

目前狀態：

`Playable Prototype`

## Bryce Game Studio 功能

- 遊戲作品卡片
- 遊戲作品介紹視窗
- 開始遊戲按鈕
- GitHub Repository 連結
- Coming Soon 未解鎖作品
- 手機與桌面版響應式設計
- 使用 JSON 管理遊戲資料
- GitHub Pages 靜態網站部署
